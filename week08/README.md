# 8주차 — 중간고사

🚧 이 주차는 새로운 실습 코드가 없습니다 (중간고사 주간). 1~7주차에 배운 것을 정리하고, 팀 프로젝트 기획서 발표 + 포트폴리오 사이트 초안으로 평가합니다.

## 이번 주 진행 방식

시험지를 푸는 형태가 아니라, 지금까지의 결과물로 평가합니다.

- **팀 프로젝트 기획서 발표** (비중 大) — 팀 구성/역할, 프로젝트 주제와 핵심 기능(MVP), 9~15주 일정 계획, 보안 고려사항 초안을 담은 A4 1~2장 기획서를 팀별로 짧게 발표합니다.
- **포트폴리오 사이트 초안 제출** (개인) — 자기소개, 1~7주차 과제 링크 모음을 담은 사이트를 직접 만들어 Vercel에 배포합니다. 지금은 초안이며 15주차 최종 발표까지 계속 키워 나갑니다.
- 그동안의 과제(#1~5) 커밋 이력과 1~7주차에서 다룬 보안 개념 이해도도 함께 봅니다.

## 팀 프로젝트 주제, 이렇게 확장해보세요

지금까지 배운 게시판 구조(목록·상세·작성·인증)를 응용하는 것이 출발점입니다.

- 커머스형 — 상품 목록/상세 + 장바구니/주문 (10~11주차 쇼핑몰 레퍼런스와 결이 비슷)
- 커뮤니티/SNS형 — 게시판 + 댓글 + 팔로우/좋아요
- 예약/매칭형 — 일정·좌석·팀원 매칭 시스템
- 우리 학과/동아리형 — 학과 공지 + 행사 + 스터디 모집 게시판

주제가 무엇이든 핵심은 "게시판형 CRUD + 인증 + 최소 하나의 보안 체크리스트"를 갖추는 것입니다.

## 발표 & 제출 방법

1. GitHub Organization에 `team-<팀명>` 레포 생성
2. 팀 레포 README(또는 별도 문서)에 기획서 업로드
3. 팀당 5분 발표 + 질의응답
4. 개인 제출란에 포트폴리오 사이트의 Vercel 배포 URL 제출

## 남은 학기 로드맵

9주차(인증 완성 + 권한 RBAC) → 10~11주차(고급 예제: 쇼핑몰 레퍼런스) → 12~14주차(OWASP 보안 실습, before/after) → 15주차(최종 발표 + 총정리, 기말).
